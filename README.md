# minerpg

A fantasy adventure modpack for Minecraft 1.21.1 (NeoForge), made for a small private server among friends:
classes and talents, races, dungeons and bosses, loot, quests and professions.

This repository is what the game downloads its updates from. You don't need to touch anything here; follow the
steps below once and the game keeps itself up to date.

## How to join

**You need:** a Minecraft Java Edition account and a computer with at least 8 GB of memory (16 GB is comfortable).

1. **Install Prism Launcher** (free): <https://prismlauncher.org/download/>. Open it and sign in with your
   Microsoft account (top right, *Accounts* → *Manage Accounts* → *Add Microsoft*).
2. **Add the pack:** click *Add Instance* → *Import*, paste this link and press *OK*:

   ```
   https://github.com/renatillas/minerpg-pack/releases/download/instance/minerpg-prism.zip
   ```

3. **First launch:** select *minerpg* and press *Launch*. A small window downloads the pack (about 300 MB; a few
   minutes). Let it finish. If Prism asks to download Java, say yes. The first start of the game itself takes a
   minute or two.
4. **Get on the list:** send the server admin your Minecraft name; the server only lets in people on its list.
5. **Join:** *Multiplayer* → *Add Server*, enter the address the admin gives you, and join.

## Updates

Every time you press *Launch*, the pack checks for a new version and downloads it first. Nothing else to do.

If the server says your game doesn't match ("mismatched mods" or similar), close the game and launch it again.
If that doesn't help, the server hasn't been updated yet; tell the admin.

## If something goes wrong

- **The game runs out of memory or your computer has only 8 GB:** right-click *minerpg* → *Edit* → *Settings* →
  *Java*, and set *Maximum memory allocation* to 4096 MiB (default is 6144).
- **The game is slow:** *Options* → *Video Settings*, lower *Render Distance* to 8.
- **The update window shows an error:** check your internet connection and launch again; a half-finished update
  is resumed next time.

## In the game

You start with the *Adventurer's Handbook*; it explains everything. The most useful keys: **L** quests,
**N** talents, **J** jobs, **H** party, **R** roll, **V** race ability, **G** accessories, **B** backpack.
